# lmoFront

Frontend React simple, structuree comme le projet GLOP (app/common/features).

## Lancer

```powershell
cd lmoFront
npm install
npm run dev
```

Puis ouvrir `http://localhost:5173`.

## Contenu actuel

- Route `/` : accueil "La Maison Orientale" (theme visuel, simple)
- Sections placeholders : carte, reservation, contact

## Prochaine etape

- Brancher la section carte sur l'API backend (`GET /api/public/menu`)
